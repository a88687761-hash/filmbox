# FilmBox — سایت ساده نمایش فیلم + پنل مدیر

## امکانات
- صفحه اصلی کاتالوگ فیلم با جست‌وجو و فیلتر ژانر
- صفحه پخش هر فیلم با HTML5 video
- پنل `/admin` برای مدیر
- افزودن و حذف فیلم با لینک MP4
- ثبت بازدیدکننده‌ها: زمان، صفحه، مرورگر و IP به‌صورت ماسک‌شده
- رمز مدیر از طریق متغیر محیطی

## اجرا روی کامپیوتر
1. Node.js نصب باشد.
2. در پوشه پروژه اجرا کنید:
   `npm install`
3. فایل `.env.example` را با نام `.env` کپی کنید و حداقل `ADMIN_PASSWORD` و `SESSION_SECRET` را تغییر دهید.
4. اجرا:
   `npm start`
5. سایت: `http://localhost:3000`
6. پنل: `http://localhost:3000/admin`

نکته: برای استقرار واقعی HTTPS، بکاپ فایل‌های `data/` و یک رمز قوی الزامی است. این قالب عمداً سازوکار دور زدن فیلترینگ یا عبور از محدودیت‌های شبکه را شامل نمی‌شود.
